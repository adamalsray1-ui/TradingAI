# Trading AI v1

هذه النسخة الأولى لا تتخذ صفقات حقيقية. وظيفتها تجهيز فيديوهات التداول كبيانات تدريب.

## التشغيل

1. ثبت Python 3.11 أو أحدث.
2. افتح الطرفية داخل هذا المجلد.
3. نفذ:

pip install -r requirements.txt

4. ضع فيديو التداول داخل:
input_videos/

5. نفذ:

python extract_frames.py

سيتم استخراج صورة كل ثانيتين تقريباً.

6. نفذ:

python make_dataset.py

سيُنشأ:
dataset/labels.csv

## المرحلة التالية

نضع لكل صورة بيانات مثل:
- setup: FVG / BOS / CHOCH / liquidity...
- direction: long / short
- entry
- stop_loss
- take_profit
- result

بعد جمع عدد كافٍ من الأمثلة يمكن تدريب نموذج رؤية للتعرف على الأنماط.

## ملاحظة

لا تجعل النموذج يتداول بأموال حقيقية مباشرة. اختبره أولاً على بيانات تاريخية وحساب تجريبي، لأن الفيديو وحده لا يثبت أن الاستراتيجية مربحة.
